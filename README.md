# Hanfei Yang — Academic Portfolio

Static GitHub Pages portfolio built with HTML, CSS, and vanilla JavaScript.

## Deployment

1. Create a **public** GitHub repository named `Hanfei-Yang.github.io` under the `Hanfei-Yang` account.
2. Upload `index.html` and the entire `assets` directory to the repository root.
3. Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then click **Save**.
4. Once GitHub Pages finishes deploying, visit `https://hanfei-yang.github.io/`.

The site contains no external image dependencies or build tooling. Edit `index.html` for content and `assets/style.css` for colors/layout.
